FICHIERS & RESPONSABILITÉS:

chat-widget.js (CORE)
├─ Crée le DOM du widget
├─ Gère l'état (open/close)
├─ Implémente la logique du chatbot
├─ Persiste les données (localStorage)
├─ Gère les événements utilisateur
└─ Charge l'historique au démarrage

style.css (DESIGN)
├─ .chat-toggle - Bouton flottant
├─ .chat-bubble - Conteneur du chat
├─ .chat-header-widget - En-tête
├─ .chat-messages-widget - Zone messages
├─ .chat-input-area - Champ saisie
├─ .message-user - Messages utilisateur
├─ .message-bot - Réponses bot
└─ Media queries responsive

HTML (INTÉGRATION)
├─ <div id="chat-widget"> - Widget créé par JS
├─ <script src="chat-widget.js"> - Initialisation
└─ Aucun HTML à ajouter manuellement

STOCKAGE DONNÉES:
└─ localStorage.chatHistory = JSON array

🚀 UTILISATION & GUIDE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

POUR LES UTILISATEURS:

1. Cliquer sur le bouton 💬 (bas-droit)
2. La fenêtre de chat s'ouvre avec animation
3. Taper un message dans le champ de saisie
4. Appuyer sur Entrée ou cliquer "Envoyer"
5. Recevoir une réponse instantanée du chatbot
6. Continuer la conversation
7. Cliquer sur "Ouvrir messagerie complète" pour un agent
8. Fermer avec le bouton × ou clic externe

POUR LES DÉVELOPPEURS:

Ajouter le chat à une nouvelle page:
```html
<script src="chat-widget.js"></script>
```

Modifier les réponses du bot:
```javascript
// Dans chat-widget.js, fonction getBotResponse()
const responses = {
    'mon-motcle': 'Ma réponse personnalisée'
};
```

Changer les couleurs:
```css
background: linear-gradient(135deg, #667eea 0%, #764ba2 100%)
/* Remplacer par vos couleurs */
```

Effacer l'historique (console):
```javascript
localStorage.removeItem('chatHistory')
```
