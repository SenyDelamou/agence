⚡ DÉMARRAGE RAPIDE

Si vous devez juste utiliser le chat:
    • Cliquez sur le bouton 💬 en bas à droite
    • Tapez votre message
    • Utilisez les onglets (Messages, Contacts, Vidéo)
    
Si vous devez faire de la maintenance:
    • Lire QUICK_REFERENCE.md (3 minutes)
    • Chercher la fonction dans chat-widget.js
    • Modifier et tester
    
Si vous trouvez un bug:
    • Ouvrir console (F12)
    • Chercher l'erreur
    • Consulter UNIFIED_CHAT_SYSTEM.md section Troubleshooting
