💬 Système de Chat Unifié

Obtenez de l'aide rapidement et facilement

📱 Vue d'Ensemble

Voyage Élégance propose un système de chat unique et unifié accessible sur toutes les pages du site. Ce système vous permet de communiquer rapidement avec notre équipe de support sans avoir besoin d'une page dédiée.

🚀 Comment Utiliser

1️⃣

Ouvrir le Chat

Cliquez sur le bouton flottant 💬 dans le coin inférieur droit de l'écran.

2️⃣

Taper un Message

Écrivez votre question ou message dans le champ de texte au bas de la fenêtre de chat.

3️⃣

Envoyer

Cliquez sur le bouton d'envoi ou appuyez sur Entrée pour envoyer votre message.

4️⃣

Accéder à la Messagerie Complète

Pour une conversation plus détaillée, cliquez sur "Ouvrir messagerie complète" pour accéder à la page de messagerie.

  • ✅ Accessible partout - Chat disponible sur chaque page du site

❓ Questions Fréquentes

Le chat est-il réel ou automatisé?

Le chat utilise une IA intelligente pour répondre aux questions courantes instantanément. Pour les questions plus complexes, vous pouvez accéder à la messagerie complète où vous parlerez avec nos agents.

Mes messages sont-ils confidentiels?

Oui, vos messages sont stockés localement dans votre navigateur et ne sont pas partagés sauf si vous les envoyez à nos agents via la messagerie complète.

Comment accéder à la messagerie complète?

Dans le chat flottant, cliquez sur le lien "Ouvrir messagerie complète" au bas de la fenêtre pour accéder à la page de messagerie détaillée.

Le chat est-il disponible sur mobile?

Absolument! Le chat est entièrement responsive et optimisé pour les appareils mobiles. Il s'adapte automatiquement à la taille de votre écran.
