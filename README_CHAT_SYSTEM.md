📞 UTILISATION
═══════════════════════════════════════════════════════════════════════════════

POUR L'UTILISATEUR

  1. Cliquer bouton 💬 (bas-droit de l'écran)
  2. Widget s'ouvre sur l'onglet Messages
  3. Taper un message, appuyer Entrée
  4. Chatbot répond automatiquement
  5. Cliquer onglet Contacts ou Vidéo pour accéder à d'autres services
  6. Historique sauvegardé automatiquement (localStorage)

POUR LE DÉVELOPPEUR

  // Consulter la réponse du chatbot
  const response = getBotResponse("réservation");

  // Charger l'historique
  loadChatHistory();

  // Ajouter un message
  addMessageToWidget("Bonjour", "user");

  // Accéder aux onglets
  switchChatTab("contacts"); // messages | contacts | video

POUR L'ADMINISTRATEUR

  • Aucune configuration requise
  • Aucune API à setup
  • Aucune base de données
  • Fonctionne offline (sauf vidéo)
  • localStorage suffit pour persistance
